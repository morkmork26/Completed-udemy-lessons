Section 1: Understanding AI agents

▼
The 20% you need to know: An AI agent is an autonomous system that perceives its environment, reasons about goals, takes actions using tools, and learns from feedback. The key difference from a chatbot: agents can ACT on the world (call APIs, write files, send emails), not just generate text. They are believed to be the next big thing because they bridge the gap between AI understanding and AI doing.
AI Agent = LLM (brain) + Tools (hands) + Memory (context) + Autonomy (decision loop)

Section 2: Essential ingredients for building AI agents

▼
The 20% you need to know: Every AI agent follows a perception-action loop with 6 components: (1) Environment provides stimuli, (2) Sensors collect data (user prompts, API responses), (3) Model interprets data (the LLM), (4) Decision-making logic selects actions (rules, policies, reasoning), (5) Actions/Actuators execute on the world (API calls, file writes), (6) Feedback evaluates and loops back. Master this loop and you understand every agent ever built.
Environment → Sensors → Model → Decision Logic → Action → Updated Environment → Repeat

Section 3: Types of AI agents: from simple to complex structures

▼
The 20% you need to know: There are 5 types, escalating in complexity: (1) Simple Reflex (if-then rules, no memory), (2) Model-Based Reflex (maintains internal state/world model), (3) Goal-Based (plans toward explicit goals), (4) Utility-Based (optimizes for best outcome using scoring), (5) Learning (improves from experience). Most production AI agents today are Goal-Based or Utility-Based. Learning agents are the frontier.
Simple Reflex < Model-Based < Goal-Based < Utility-Based < Learning Agent

Glossary of Key Terms

▼
AI Agent

An autonomous system that perceives its environment, reasons about goals, takes actions using tools, and learns from feedback.

Agentic Workflow

A predefined sequence of steps executed the same way every time. No dynamic decision-making. Think assembly line.

API

A bridge connecting your agent to external services (LLMs, databases, email). How agents access their brain and tools.

Chain of Thought (CoT)

A prompting technique where the model shows reasoning step-by-step before giving a final answer.

CrewAI

A framework organizing groups of agents with backstories and goals, coordinating through built-in task delegation.

Few-Shot Prompting

Providing examples of desired input/output pairs so the model learns the expected pattern.

Guardrails

Constraints and safety mechanisms keeping an agent operating within acceptable boundaries.

Human-in-the-Loop

A design pattern where humans review, approve, or override agent decisions at critical points.

LangChain

The most popular agent framework. Offers chains (workflows) and agents (dynamic reasoning), plus LangGraph.

LLM

The neural network serving as an agent's brain for reasoning and language understanding.

Memory (Agent)

The ability to retain information across interactions. Short-term (context window) and long-term (vector store/database).

Multi-Agent System

Multiple specialized agents collaborating on a task, each with distinct roles and capabilities.

n8n

A visual workflow automation tool using drag-and-drop nodes for building AI agents without coding.

RAG

Retrieval-Augmented Generation: agent retrieves relevant documents before generating a response, grounding in specific data.

ReAct

Reasoning + Acting: interleaves thinking with acting (using tools), looping until the task is complete.

ReWoo

Reasoning Without Observation: plans ALL steps upfront before executing any, reducing LLM calls and cost.

System Prompt

The instruction set defining an agent's role, behavior, constraints, and tool usage rules.

Tool (Agent)

An external capability an agent can invoke: APIs, databases, code execution, web search, email.
